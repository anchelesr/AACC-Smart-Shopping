# ADR-004: Time-shift forecasts according to carbon intensity with an SLO deadline

- **Status:** Proposed (Assignment 1)
- **Decision owners:** Project team (student)
- **Scope:** Smart Shopping AACC architecture

## Context
Forecast batch work is deferrable; the final project requires simulated carbon-aware behavior and explicit SLOs.

## Decision
Run due forecasts when simulated intensity is below configurable threshold, but force execution at maximum age/deadline; record decision and carbon estimates.

## Alternatives considered
Always run immediately; move jobs across regions; only choose smallest model.

## Consequences / trade-offs
Makes response to carbon intensity demonstrable with minimal extra infrastructure; introduces stale-result risk, requires deadline enforcement, and savings are unproven until compared with baseline.
