# ADR-005: Kubernetes Deployments, CronJobs and metrics

- **Status:** Proposed (Assignment 1)
- **Decision owners:** Project team (student)
- **Scope:** Smart Shopping AACC architecture

## Context
Later milestones require Kubernetes and operational evidence; scheduled work and always-on API have different lifecycles.

## Decision
Use frontend/API Deployments and Services; importer and forecast-batch CronJobs; Postgres with persistent storage; Prometheus-compatible metrics.

## Alternatives considered
Run all tasks permanently inside API Deployment; serverless-only design; manually run scripts.

## Consequences / trade-offs
Clear resource boundaries and reproducible demo; Kubernetes learning/operational overhead, possible CronJob duplication and database persistence complexity.
